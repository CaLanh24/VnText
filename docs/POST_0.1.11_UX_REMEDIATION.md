## Persisted product decision

“Lấy text chỉ lấy text/OCR; dịch ảnh thuộc bước dịch. Không bỏ capability ảnh, không chỉ đổi nhãn khi backend vẫn dịch.” Extract may inventory images and perform OCR, but must not machine-translate or render image text. Image translation/rendering belongs to Translate and must remain supported end to end. The backend route must change along with the UI.

## Scope and invariants

- Every run has one task ID, owner view, lifecycle state, and terminal result. Delayed progress for a prior run cannot alter a completed or newer run.
- Cancel has observable requested, acknowledged/accepted, terminal, timeout, and recovery outcomes. Cancel-and-exit waits for safe completion/rollback and never kills a writer blindly.
- Extract, Translate, and Patch retain independent run state and progress. Navigating between pages cannot create fake progress or change another task's displayed state.
- Image extraction/OCR and image MT/render are separate; source ownership, image delivery, approval invalidation, output receipt, and rollback protections remain intact.
- Translate readiness distinguishes package validity, blank translation eligibility, model readiness, running, completion, cancellation, and failure. ETA remains advisory; completion is terminal-event driven.
- CSV editor handles the existing large-file range (including ~27k rows) responsively, keeps edits and validation actionable, preserves schema/order/source fields and exact input on failed save/import, and makes cancel/reload/dirty state explicit. No validator is weakened.
- Audit dialogs, toasts, tooltips, theme colors, accessibility/focus, minimum window sizing, and resize/DPI behavior. Newly found risks are labeled separately from confirmed defects.
- Release notes/update UX displays the correct version/date and Vietnamese customer-facing notes, scrollable content and fixed close action, and a correct download route. Compatibility matrix covers every actually published baseline to latest, with each exact route/hash/provenance contract intact.
